# Tasty Bites - Food Ordering App

A simple food ordering web application built using HTML, CSS and JavaScript.

## Live Demo
https://eethayathullas-prog.github.io/Tasty-Bites/

## Features
- User Register and Login
- Food menu with images
- Category filter and search
- Add to cart with quantity change
- Bill with GST and delivery charge
- Payment page (Cash on Delivery, UPI, Card)
- Order history for each user

## Technologies Used
- HTML - page structure
- CSS - design and layout
- JavaScript - cart, login, payment and order logic
- localStorage - saving users and orders in the browser

## Project Structure
- index.html - all pages (login, menu, payment, history)
- style.css - styling
- script.js - functions and logic
- images/ - food photos

## How to Run
1. Download or clone this repository.
2. Open index.html in a browser.

## Note
This is a personal project. Data is stored in the browser (localStorage), and card payment is only for demo.
